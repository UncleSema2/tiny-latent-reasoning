# LUT teacher trajectory audit

The one-epoch Qwen2.5-VL-7B teacher reached 67.68% teacher-forced answer-token accuracy on 512 held-out Visual-CoT images. Its reference answer cross-entropy was 1.192 and 194 of 512 answers matched at every reference position. These measurements use the gold answer prefix at each position. The separate trajectory audit asks whether the frozen base model assigns a higher mean log probability to the reference answer when given teacher states than when given per-step norm-matched random vectors. Each question has equal weight. [LUT trajectory scoring](https://arxiv.org/html/2608.00743v1#S3.SS2)

## Reproduce

Start from the full teacher checkpoint with its processor and the `held-out.json` generated by teacher validation. Set `TEACHER`, `IMAGES`, `TRAIN` and `ANNOTATIONS` to the checkpoint directory, Visual-CoT image root, 60K training JSONL and original annotation file respectively. Run from the repository root with four GPUs. Each rank needs memory for both 7B models in bfloat16. Use a fresh output directory per run.

```sh
for offset in 0 512; do
    uv run --frozen --extra train torchrun --standalone --nproc-per-node=4 \
        -m methods.lut.audit_trajectory --teacher "$TEACHER" --images "$IMAGES" \
        --train "$TRAIN" --annotations "$ANNOTATIONS" --skip "$offset" \
        --count 512 --output "audit-$offset" &&
    uv run --frozen --extra train -m methods.lut.summarize_audit "audit-$offset" || exit 1
done
```

The sampler shuffles source rows with seed 43, excludes training image paths and keeps one question per remaining image path. The second run takes the next 512 images in the same order. The per-question control seed uses the absolute position in this order. For the wrong-image comparison, each rank takes the previous image in its shard with wraparound and matches its state norms to the current image.

## What the judge sees

The original evaluator injects the eight vectors consumed by the teacher's recurrent slots. The first comes from the opening delimiter. The shifted variant takes the eight outputs of the slots, including the output of the final slot. Every comparison uses the same prompt, reference answer, positions and delimiter vectors in both arms. The trained-delimiter variant supplies the teacher's two learned input vectors to the frozen judge. This changes the judge input protocol.

Both reserved delimiter rows in the base model have zero norm. After teacher training, the opening and closing rows have norms of 0.01950 and 0.02906. The closing delimiter predicts the first answer token. A tiny multimodal model in float32 checks that the recurrent teacher, reference forward, batched judge and native shifted-label loss agree on their answer positions for both single-token and multi-token answers.

On the first 512 images the original batched evaluator exactly replayed all saved answer losses and utility deltas (mean Δ −0.545). The native single-example forward gave mean Δ −0.530 on the same inputs. Its mean absolute per-question deviation from the batched result was 0.119 in bfloat16. The second random draw gave mean Δ −0.500. Rescaling all states and controls to ordinary text embedding magnitude gave mean Δ −0.925.

With teacher delimiters and slot inputs, 439/512 questions on the original split and 446/512 on the confirmation split passed the Δ > −0.5 selection threshold against random directions. With base delimiters the corresponding native-forward counts were 278 and 271. The confirmation split also favored states from the same example over states from another image and question. This control measures example specificity and cannot separate contributions from the image and the question.

For a student pilot, retain the eight recurrent inputs and transfer the two learned delimiter vectors to the judge's input. Record that choice alongside the original frozen-base protocol. The measured outcome is teacher-forced reference likelihood. Student task performance requires a separate evaluation.
